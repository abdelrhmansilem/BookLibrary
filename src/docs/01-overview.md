# 1. نظرة عامة على المشروع

**BookLibrary** تطبيق واجهة أمامية (Front-End) يعرض معرضًا للكتب العالمية. المستخدم يبحث، يتنقّل بين الأقسام، يفتح صفحة أي كتاب، ويحفظ ما يعجبه في مفضلته. الموقع ثنائي اللغة (عربي/إنجليزي) ويدعم الوضع الداكن.

## الفكرة في سطر واحد

> واجهة واحدة تجمع آلاف الكتب من Open Library، وتعرضها بالعربية والإنجليزية بشكل بسيط وسريع.

## ما الذي يفعله المستخدم؟

- يفتح الصفحة الرئيسية فيرى عنوانًا تعريفيًا، حقل بحث، كتبًا مختارة، ثم الأقسام.
- يبحث بالعنوان أو اسم المؤلف، أو يختار قسمًا مثل «علوم» أو «تاريخ».
- يفتح صفحة الكتاب فيرى الغلاف والمؤلف وسنة النشر والوصف والمواضيع المرتبطة.
- يضيف الكتاب إلى المفضلة، فتبقى محفوظة في متصفحه.
- يبدّل اللغة فيصبح الاتجاه من اليمين إلى اليسار، ويبدّل الثيم الداكن والفاتح.

## ما الذي لا يفعله المشروع؟

المشروع **واجهة أمامية فقط**:

- لا يوجد خادم (backend) ولا قاعدة بيانات.
- لا يوجد تسجيل دخول أو حساب مستخدم.
- لا يوجد شراء أو دفع.
- نموذج «تواصل معنا» لا يرسل أي شيء؛ التحقق يحدث في المتصفح فقط.

هذا اختيار مقصود: المشروع الجامعي يهدف إلى إتقان React وليس بناء نظام كامل.

## التقنيات

- **React 19** لبناء الواجهة من مكوّنات.
- **Vite 8** لتشغيل المشروع محليًا وبناء النسخة النهائية.
- **React Router 7** للتنقل بين الصفحات دون إعادة تحميل.
- **CSS Modules** لتنسيق كل مكوّن بمعزل عن غيره.
- **Open Library API** كمصدر بيانات حقيقي ومجاني.
- **localStorage** لحفظ اللغة والثيم والمفضلة.

## هيكل المجلدات

```
src/
  components/   مكوّنات قابلة لإعادة الاستخدام
  context/      الحالة المشتركة (اللغة، الثيم، المفضلة)
  data/         قائمة الأقسام الثابتة
  docs/         هذا الشرح (يُقرأ ويُعرض داخل صفحة /docs)
  hooks/        useDebounce, useFetch
  locales/      ملفات الترجمة ar.js و en.js
  pages/        صفحة لكل مسار
  services/     التعامل الوحيد مع الشبكة
  styles/       متغيرات التصميم والستايل العام
  utils/        دوال مساعدة صغيرة
```

## من أين أبدأ القراءة؟

1. `src/main.jsx` — نقطة الدخول وتركيب المزوّدات.
2. `src/App.jsx` — جدول المسارات.
3. `src/components/layout/Layout.jsx` — الهيكل العام.
4. `src/pages/Home.jsx` — أول صفحة يراها المستخدم.
5. `src/services/openLibrary.js` — كيف نجلب البيانات.
