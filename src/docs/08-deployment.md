# 8. النشر على Vercel

## الخطوات

1. الريبو على GitHub: `abdelrhmansilem/BookLibrary`.
2. الدخول إلى [vercel.com](https://vercel.com) ثم **Add New Project**.
3. اختيار الريبو، فيكتشف Vercel تلقائيًا أنه مشروع Vite.
4. التأكد من الإعدادات:
   - Framework Preset: **Vite**
   - Build Command: `npm run build`
   - Output Directory: `dist`
5. **Deploy**. يستغرق أول نشر دقيقتين تقريبًا.
6. كل `git push` إلى `main` يعيد النشر تلقائيًا.

## ملف vercel.json

```json
{
  "rewrites": [{ "source": "/(.*)", "destination": "/index.html" }]
}
```

بدون هذا السطر، فتح رابط داخلي مثل `/books/OL45804W` مباشرة يعطي 404 من الخادم، لأن الخادم لا يملك ملفًا بهذا الاسم. القاعدة تعيد كل الطلبات إلى `index.html` ويتولى React Router العرض.

## الفرق بين dev و build

| | dev | build |
|---|---|---|
| الأمر | `npm run dev` | `npm run build` |
| السرعة | فوري مع إعادة تحميل | مصغّر ومحسّن |
| الاستخدام | التطوير | الإنتاج |

قبل أي تسليم: `npm run build` ثم `npm run preview` للتأكد أن النسخة النهائية تعمل.

## قائمة تحقق قبل النشر

- `npm run build` ينتهي بدون أخطاء.
- لا توجد مفاتيح أو أسرار في الريبو.
- الصفحات كلها تعمل بعد إعادة التحميل (اختبار الـ rewrites).
- الثيم واللغة يبقيان بعد إعادة تحميل الصفحة.
- الرابط يعمل على الموبايل.

## استكشاف الأخطاء

- **404 عند فتح صفحة داخلية** → تأكد من وجود `vercel.json`.
- **شاشة بيضاء** → افتح Console؛ غالبًا مسار استيراد خاطئ بحرف كبير أو صغير.
- **البيانات لا تظهر** → قد يكون Open Library بطيئًا؛ جرّب زر «حاول مرة أخرى».
