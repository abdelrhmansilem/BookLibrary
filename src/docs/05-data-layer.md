# 5. طبقة البيانات و Open Library

## القاعدة

كل نداء شبكة في المشروع موجود في ملف واحد: `src/services/openLibrary.js`. لا يوجد `fetch` في أي مكوّن.

## لماذا Open Library؟

- بيانات حقيقية لكتب عالمية (من Internet Archive).
- لا تحتاج مفتاحًا (API key) ولا تسجيلًا.
- تدعم CORS، أي أن المتصفح يستطيع الاتصال بها مباشرة.
- مجانية بالكامل.

## الدوال المتاحة

### `searchBooks({ query, subject, page, signal })`

```js
const { books, total } = await searchBooks({ query: "tolkien", page: 1 });
```

- تبني الاستعلام: `q=tolkien` أو `q=subject:"history"` أو الاثنين معًا.
- تستخدم `URLSearchParams` لترميز الرابط بشكل صحيح.
- تطلب فقط الحقول التي نعرضها، فتكون الاستجابة أصغر وأسرع.
- تُعيد `{ books, total, page }`.

### `getTrendingBooks(limit, { signal })`

تجيب الكتب الشائعة في الصفحة الرئيسية من `/trending/daily.json`. إذا فشل الطلب نعود إلى بحث عام داخل نطاق `fiction` حتى لا تظهر الصفحة الرئيسية فارغة.

### `getBook(id)`

تجيب تفاصيل عمل واحد من `/works/{id}.json`، ومنها الوصف والمواضيع.

## التطبيع (normalization)

واجهة Open Library تُعيد أشكالًا مختلفة: الوصف قد يكون نصًا أو كائنًا `{ value }`، والأغلفة قد تكون `cover_i` أو `covers`، وعند بعض الكتب لا يوجد مؤلف.

`normalizeBook()` تحوّل كل ذلك إلى شكل واحد ثابت:

```js
{ id, title, author, year, cover, description, subjects }
```

الفائدة: كل المكوّنات تتعامل مع شكل واحد فقط، ولا نكرر «إذا لم يوجد كذا استخدم كذا» في كل صفحة.

## معالجة الأخطاء

- `AbortController` يلغي الطلب عند مغادرة الصفحة، فلا نحدّث حالة مكوّن غير موجود.
- مؤقّت 12 ثانية يمنع انتظارًا لا نهائيًا.
- الأخطاء مصنّفة: `timeout`، `network`، `not-found`، `http`. الصفحة تختار الرسالة المناسبة.
- كل صفحة تعرض ثلاث حالات على الأقل: تحميل، خطأ مع زر إعادة، وفراغ.

## لماذا debounce؟

لو أرسلنا طلبًا مع كل حرف يكتبه المستخدم، لكتبنا 10 طلبات في أقل من ثانيتين. `useDebounce` يؤخّر تنفيذ البحث حتى يتوقف المستخدم عن الكتابة 450 مللي ثانية.

## الأغلفة

```
https://covers.openlibrary.org/b/id/{cover_i}-M.jpg
```

الأحرف: `S` صغير، `M` متوسط، `L` كبير. جزء كبير من الكتب لا يملك غلافًا، لذلك `BookCover` يعرض بديلًا أنيقًا بدل صورة مكسورة.
